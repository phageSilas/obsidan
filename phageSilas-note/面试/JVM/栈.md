Java虚拟机栈（Java Virtual Machine Stack），通常简称为**JVM栈**或**栈内存**，是Java程序运行时的核心内存区域之一。理解它对于排查线上问题（特别是内存和性能相关的Bug）以及准备技术面试都至关重要。
![[image-12.png]]




## 1. 核心作用与特点

- **线程私有（Thread-Private）：** JVM栈的生命周期与线程相同。每当你在Java中启动一个新线程，JVM就会为这个线程分配一个专属的栈。这意味着栈内存里的数据是线程安全的，不需要考虑多线程并发同步的问题。
    
- **方法执行的模型：** 栈是用来描述Java方法执行的内存模型的。线程在每执行一个方法时，都会同步创建一个叫做“栈帧”（Stack Frame）的数据结构。
    
- **后进先出（LIFO）：** 栈的操作遵循后进先出的原则。方法被调用时入栈（Push），方法执行结束（无论是正常返回还是抛出异常）时出栈（Pop）。

## 2. 栈的微观结构：栈帧（Stack Frame）

栈是由一个个“栈帧”组成的。你可以把JVM栈想象成一个弹夹，而栈帧就是里面的一颗颗子弹。每次调用一个方法，就会有一颗子弹被压入弹夹；方法执行完毕，这颗子弹就被弹出,即栈中的数据具有确定的生命周期，当一个方法调用结束时，其对应的栈帧就会被销毁，栈中存储的局部变量也会随之消失。

一个完整的栈帧主要包含以下四个部分：

### A. 局部变量表 (Local Variable Table)
![[image-13.png]]

顾名思义，这里存放的是方法内部定义的变量。

- **存放内容：** 编译期可知的各种Java基本数据类型（`boolean`、`byte`、`char`、`short`、`int`、`float`、`long`、`double`）、对象引用（即上一个问题中提到的 `A a` 那个内存地址句柄）以及 `returnAddress` 类型。
    
- **分配时机：** 局部变量表所需的内存空间在**编译期间**就已经完全确定了。当进入一个方法时，这个方法需要在栈帧中分配多大的局部变量空间是完全确定的，在方法运行期间不会改变其大小。
    

### B. 操作数栈 (Operand Stack)

这是一个临时的计算工作区。

- **作用：** 在方法执行的过程中，根据字节码指令，往栈中写入数据或提取数据。比如执行 `int c = a + b;` 这个操作时，JVM会先把 `a` 和 `b` 的值从局部变量表压入操作数栈，然后执行加法指令，引擎将操作数栈顶的两个元素取出相加，再把结果 `c` 压回操作数栈，最后再赋值给局部变量表。
    

### C. 动态链接 (Dynamic Linking)

- **作用：** Java的特性是多态，有些方法的具体实现在编译期是不知道的（比如接口的具体实现类的方法）。每个栈帧都包含一个指向运行时常量池中该栈帧所属方法的引用，持有这个引用是为了支持方法调用过程中的动态链接。它会在程序运行期间，将符号引用转化为具体的直接引用。
    

### D. 方法出口 / 返回地址 (Return Address)

- **作用：** 记录方法执行完后，应该回到哪里去继续执行。方法退出的方式有两种：
    
    1. **正常完成出口：** 遇到方法返回的字节码指令（如 `return`）。
        
    2. **异常完成出口：** 在方法执行中遇到了异常，且没有被捕获（没有 `catch` 块），会导致方法退出。

## 3. JVM栈可能引发的两种经典错误

在实际开发和日常排查中，栈往往会报两种典型的错误，这也是面试官常考的知识点：

1. **`StackOverflowError`（栈溢出）：**
    
    - **原因：** 线程请求的栈深度大于JVM所允许的最大深度。
        
    - **常见场景：** 最常见的就是**无限递归**。比如方法A不停地调用方法A自己，导致栈帧不断被压入栈中，撑爆了栈的最大容量。
        
    - **调优参数：** 可以通过 `-Xss` 参数来设置每个线程栈的大小（例如 `-Xss1M`）。
        
2. **`OutOfMemoryError`（内存溢出）：**
    
    - **原因：** 如果JVM栈容量可以动态扩展，当尝试扩展时无法申请到足够的内存，或者在创建新线程时没有足够的内存去创建对应的栈，就会抛出该异常。
        
    - **注意：** 在HotSpot虚拟机中，栈容量是不可动态扩展的，所以通常单线程下只会抛出 `StackOverflowError`。但如果是不断创建新的线程导致内存耗尽，则会抛出 `OOM`。
