## 第1章 传感器概述

### 1.1 什么是传感器

- **传统传感器**：完成从非电量到非电量的转换，无法实现自动测量。
- **现代传感器**：以**电量为输出**的传感器，可满足精确度、速度、远距离测量等需求。
- **被测对象**：工业上需要检测的量分为**电量**和**非电量**两大类。

### 1.2 传感器技术的作用和地位

现代信息技术的**三大支柱**：

| 技术        | 作用       |
| --------- | -------- |
| **传感器技术** | 信息采集（感官） |
| **通信技术**  | 信息传输（神经） |
| **计算机技术** | 信息处理（大脑） |

> 传感器是获取信息的主要途径和手段。

### 1.3 传感器现状与发展趋势

1. 发现、利用新效应（磁光、压阻）
2. 开发新材料（光纤、PVC、稀土）
3. 提高传感器性能和检测范围
4. **微型化与微功耗**（微米、微安、毫克）
5. **集成化与多功能化**
6. **智能化**（自校、自诊断、自补偿、存储、数字输出）
7. **数字化和网络化**

### 1.4 检测系统的组成原理

**微机测试系统**（开环）：
```
非电量 → 传感器 → 测量电路 → A/D转换 → 微机 → 显示器
```

![[Pasted image 20260624222140.png|434]]
**自动控制系统**（闭环）：
```
被测量 → 传感器 → 信号处理 → 显示/记录 → 控制器 → 反馈
```
![[Pasted image 20260624222202.png|446]]
> 现代传感技术是自动检测、自动控制及机电一体化的**第一基础**。

### 1.5 传感器的定义、组成和分类

**定义**（GB7665-87）：
> 能够感受规定的被测量并按照一定规律转换成可用输出信号的器件和装置

**含义**：
- 由**敏感元件**和**转换元件**构成的检测装置
- 按一定规律将被测量转换成**电信号**输出
- 输出与输入之间存在确定的关系
- 别称：变换器、换能器、探测器

**基本框图**：
```
被测量 → [传感器] → 电信号
```

## 第2章 传感器基本特性

### 概述

传感器可看作一个有输入/输出的**二端网络**：

- **慢变信号（静态）** → 研究**静态特性**：输入量不随时间变化或者变化极其缓慢
- **快变信号（动态）** → 研究**动态特性**：输入量随时间变化较快

### 2.1 传感器的静态特性

#### （1）线性度

- 理想传感器具有线性输入输出关系，实际多为非线性
- 多项式表示：$y = a_0 + a_1x + a_2x^2 + a_3x^3 + \cdots + a_nx^n$
- 实际中做**近似线性化**处理（切线法、割线法等）

**非线性误差**：
$$
e_L = \frac{\Delta L_{\text{max}}}{Y_{FS}} \times 100\%
$$
- $\Delta L_{\text{max}}$ — 最大非线性绝对误差
- $Y_{FS}$ — 满量程输出
- ![[Pasted image 20260625085522.png|424]]

**拟合方法**：

| 方法 | 说明 |
|------|------|
| **理论线性度** | 以0%~100%端点作直线 |
| **端基线性度** | 实际曲线起点与终点的连线 |
| **独立线性度** | 端基线平移，等距包围所有标定点 |
| **最小二乘法线性度** | 精度最高，最常用 |
 ![[Pasted image 20260625094821.png|423]]
#### （2）迟滞

- 传感器正、反行程期间输出特性曲线**不重合**的现象
- **原因**：敏感元件材料的物理性质缺陷（弹性滞后、铁磁/铁电滞后）
![[Pasted image 20260625095057.png|275]]
**迟滞误差**：
$$
e_H = \frac{\Delta H_{\text{max}}}{Y_{FS}} \times 100\%
$$
![[Pasted image 20260625095009.png|635]]
#### （3）重复性

- 输入量按同一方向多次测量时输出特性**不一致**的程度
- 属于**随机误差**，可用标准偏差 $\sigma_{\text{max}}$ 表示
- 置信度取 $2\sigma \sim 3\sigma$（概率 95.4%~99.7%）
- 产生不重复的原因与迟滞产生的原因基本相似，也存在不稳定问题
- ![[Pasted image 20260625095739.png|474]]

#### （4）灵敏度

- 单位输入变量引起的输出变化量
- 在稳定条件下输出微小增量与输入微小增量的比值 

**线性传感器**：$S = \Delta y / \Delta x$（常数）
**非线性传感器**：$S = dy/dx$（变量）
![[Pasted image 20260625101305.png|233]]
![[Pasted image 20260625101333.png|243]]
- 单位示例：mV/mm（位移）、mV/℃（温度）
- 实际灵敏度需除以供电电压：mV/mm·V

#### （5）分辨率和阈值

| 概念 | 说明 |
|------|------|
| **分辨率** | 传感器能检测到的**最小输入增量** |
| **阈值（门槛灵敏度）** | 输入小到输出不再变化时的输入值 |

**产生门槛的原因**：
1. 输入变化被传感器内部吸收，未反映到输出端
2. 输出存在噪声，信号必须大于噪声电平

#### （6）漂移

- 输入量不变，输出量改变的现象

| 类型 | 子类 |
|------|------|
| **零点漂移** | 时漂 / 温漂 |
| **灵敏度漂移** | 时漂 / 温漂 |
![[Pasted image 20260625103511.png|327]]![[Pasted image 20260625103525.png|346]]
- **时漂**：在规定条件下，随时间缓慢变化
- **温漂**：随温度变化引起的漂移

## 第3章 电阻式传感器（应变式传感器）

### 概述

- 将非电量转换成**电阻值变化**，再经转换电路变成电量输出
- **主要特征**：
  - 类型：金属应变片、半导体应变片
  - 优点：结构简单、精度高、范围大、体积小
  - 缺点：电阻及半导体特性随温度变化

### 3.1 金属丝电阻应变片

#### 1. 应变片结构

```
金属丝式应变片：
  网状敏感栅（高阻金属丝/金属箔）
  + 基片（绝缘材料）
  + 盖片（保护层）
```

- 金属丝式：敏感栅用 $\phi 0.025\text{mm}$ 金属丝
- 金属箔式：截面为矩形，可通过大电流，适于批量生产
- 金属薄膜型：真空蒸镀，纳米级厚度
- 1：网状敏感栅 —— 高阻金属丝、金属箔，2：引线端子（或焊盘）3：基片
![[Pasted image 20260625104450.png]]
#### 2. 工作原理 — 电阻应变效应

导体在外力作用下产生机械形变时**阻值发生变化**。

金属丝电阻：$R = \rho \frac{L}{S}$，$$\frac{\Delta R}{R} = \frac{\Delta l}{l} - \frac{\Delta S}{S} + \frac{\Delta \rho}{\rho} $$
受轴向拉力时，几何尺寸变化引起电阻变化：
$$
\frac{dR}{R} = (1 + 2\mu) \frac{dL}{L} + \frac{d\rho}{\rho}
$$
- $\mu$ — 泊松系数（钢 $\mu = 0.285$，一般 $0.25 \sim 0.5$）
- 灵敏度系数近似：$k_0 \approx 1 + 2\mu \approx 1.5 \sim 2$
![[Pasted image 20260625105252.png|451]]
> 通过弹性元件，可将位移、压力、振动等物理量通过应力变化转换为电阻变化。

### 3.2 电阻应变片测量电路 — 直流电桥

#### ① 直流电桥平衡条件

$$
U_0 = E \left( \frac{R_1}{R_1 + R_2} - \frac{R_3}{R_3 + R_4} \right)
$$
![[Pasted image 20260625105407.png|300]]
平衡条件：$R_1 R_4 = R_2 R_3$（对臂积相等 , 邻臂比相等）

#### ② 电压灵敏度
$$U_0 \approx {k_u} \cdot \frac{\Delta R}{R}$$
- $K_u$ 与电源 $E$ 成正比，但受应变片功耗限制
$$
K_u = \frac{n}{(1+n)^2} \cdot E
$$
- $K_u$ 是桥臂比 $n$ 的函数，$n=1$,$R_1=R_2$,$R_3=R_4$（等臂）时 $K_u$ 最大

**单臂工作**：
$$
U_0 \approx \frac{E}{4} \cdot \frac{\Delta R}{R}
$$

#### ③ 非线性误差补偿 — 差动电桥
![[Pasted image 20260625110638.png|225]]![[Pasted image 20260625110740.png|378]]]
**半桥电路**（两个工作片，一拉一压）：
$$
U_0 \approx \frac{E}{2} \cdot \frac{\Delta R}{R}
$$
- 输出与 $\Delta R/R$ 呈线性，**无**非线性误差
- 灵敏度是单臂电桥的 **2 倍**
- 具有**温度补偿**作用
![[Pasted image 20260625111122.png|521]]
**全桥电路**（四个工作片）：
ΔR1=ΔR2=ΔR3=ΔR4
$$
U_0 \approx E \cdot \frac{\Delta R}{R}
$$
- 灵敏度是单臂电桥的 **4 倍**
- 无非线性误差
![[Pasted image 20260625113439.png|315]]![[Pasted image 20260625113445.png|303]]

| 电桥形式 | 输出电压 | 灵敏度倍数 | 非线性误差 |
|----------|----------|------------|------------|
| 单桥 | $\frac{E}{4}\cdot\frac{\Delta R}{R}$ | 1 | 有 |
| 半桥 | $\frac{E}{2}\cdot\frac{\Delta R}{R}$ | 2 | 无 ✅ |
| 全桥 | $E\cdot\frac{\Delta R}{R}$ | 4 | 无 ✅ |

## 第4章 电容式传感器

### 概述

- 传统应用：位移、角度、振动、加速度等精密测量
- 现代应用：压力、压差、液面、成分含量等
- **特点**：
  - 电容量小（几十~几百 pF），输出阻抗高
  - 极板静电引力小，所需作用力小
  - 可动质量小，固有频率高，动态响应好
  - 功率小，本身发热影响小
  - **可进行非接触测量**

### 4.1 工作原理

平板电容：
$$
C = \frac{\varepsilon_0 \varepsilon_r S}{\delta}
$$
- $\varepsilon_0$ — 真空介电常数
- $\varepsilon_r$ — 相对介电常数（空气 ≈ 1）
- $S$ — 极板面积
- $\delta$ — 极板距离

**三种基本类型**：

| 类型       | 变化量             | 输出特性      |
| -------- | --------------- | --------- |
| **变极距型** | $\delta$        | 非线性，适合小位移 |
| **变面积型** | $S$             | 线性，适合大位移  |
| **变介质型** | $\varepsilon_r$ | 用于液位、成分测量 |

### 4.2 输出特性

#### 1. 变极距型

灵敏度：
$$
k_0 = \frac{\Delta C/C_0}{\Delta \delta} \approx \frac{1}{\delta_0}
$$
- 灵敏度 $k_0$ 与初始极距 $\delta_0$ 成反比
- 减小 $\delta_0$ 可提高灵敏度，但受击穿电压限制
- 量程与灵敏度、线性度矛盾，适合测**小位移**
- 为改善非线性，一般采用**差动结构**

**差动结构特点**：
- 动极板移动时 $C_1$ 增加，$C_2$ 减小
- 灵敏度是单个的 **2 倍**
- 非线性误差大幅**减小**
![[Pasted image 20260625114801.png|445]]
#### 2. 变面积型（平板）

$$
C = C_0 + \frac{\varepsilon_0 \varepsilon_r b}{\delta} \cdot \Delta x
$$
![[Pasted image 20260625114856.png|154]]![[Pasted image 20260625115006.png|492]]
- 输出与位移 $\Delta x$ 成正比（线性）
- 灵敏度 $k_0$ 为常数
- 适合大位移测量
- 可实现直线位移和角位移测量

### 4.3 测量电路

#### 1) 等效电路
![[Pasted image 20260625115611.png|426]]
电容传感器等效电路包含：
- 传感器电容 $C_0$
- AB两端导线分布电容 $C_p$（$C_p > C_0$）
- 传输线电感 $L_0$、电阻 $R$（小）
- 极板等效漏电阻 $R_g$

> 低频时 $X_c$ 大，$L$、$R$ 可忽略；高频时不可忽略。工作频率 > 10MHz 需考虑电缆电感。

**解决方法**：
- 屏蔽转换元件，消除静电场和交变磁场
- 前级紧靠转换元件装在同一壳体内
- **驱动电缆技术**（等电位屏蔽）：连接电缆采用双层屏蔽，内屏蔽与被屏蔽导线电位相同，消除容性漏电

#### 2) 交流电桥（变压器式）

差动电容接入变压器电桥：
- 极板在中间位置时电桥平衡
- 动片上移时，输出电压与位移变化成**理想线性关系**
![[Pasted image 20260625120242.png|347]]![[Pasted image 20260625120301.png|298]]

## 第5章 电感式传感器

### 概述

- 利用**电磁感应定律**将位移、压力、振动等转换为电感（自感/互感）变化
- 特点：体积大，灵敏度高，输出信号大，在自动控制设备中广泛应用，机电转换装置
- **分类**：
  - 自感式电感传感器
  - 互感式电感传感器
  - 电涡流式电感传感器

### 5.1 变磁阻式（自感式）电感传感器

#### 5.1.1 工作原理

**结构**：铁芯 + 线圈 + 衔铁
![[Pasted image 20260625120714.png|527]]
磁路总磁阻：$R_m \approx R_\sigma = \frac{2\delta}{\mu_0 S_0}$
- $\delta$ — 气隙厚度,铁芯和衔铁之间的气隙
- $\mu_0$ — 真空导磁率
- $S_0$ — 气隙截面积
![[Pasted image 20260625120831.png|433]]
线圈电感量：
$$
L = \frac{N^2}{R_m} \approx \frac{N^2 \mu_0 S_0}{2\delta}
$$
- $N$ — 线圈匝数

**两种类型**：
- **变气隙厚度型**（改变 $\delta$）
- **变气隙截面积型**（改变 $S_0$）

#### 5.1.2 输出特性（变气隙厚度型）

- $L$ 与 $\delta$ 呈**反比**关系（非线性）
- 初始电感：$L_0 = \frac{N^2 \mu_0 S_0}{2\delta_0}$
- 衔铁位移 $\Delta\delta$ 引起的电感变化呈非线性
![[Pasted image 20260625120956.png|210]]
**讨论**：
- 测量范围 $\Delta\delta$ 与灵敏度 $k_0$ 相矛盾
- $\Delta\delta/\delta_0$ 越小，非线性越小，但量程变小
- 适合小位移测量，一般取 $\Delta\delta/\delta_0 = 0.1 \sim 0.2$
- 实际多采用**差动形式**减小非线性

### 5.3 电涡流式传感器

#### 特点

- **非接触式**线性化计量工具
- 准确测量金属导体与探头端面的**静态和动态相对位移**
- 可非接触测量：位移、厚度、表面温度、速度、应力、材料损伤等
- 主要应用于位移、振动、转速、厚度等机械量测量,另外可测材料、测温度和电涡流探伤。

#### 5.3.1 电涡流效应

> 金属导体置于变化磁场中或切割磁力线时，导体内部产生一圈圈闭合电流 → **电涡流** → **电涡流效应**

**形成条件**：
1. 存在**交变磁场**
2. 金属导体处于交变磁场中

**应用领域**：
- 位移、振动、转速、厚度等机械量测量
- 材料检测
- 温度测量
- 电涡流探伤
