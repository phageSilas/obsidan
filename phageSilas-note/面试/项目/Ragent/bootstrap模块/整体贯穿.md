# 作用
![[image.png]]
将其他模块（framework、infra-ai、mcp-server）的组件全部聚合到一处，通过 Spring Boot 进行自动装配、依赖注入和应用启动

# 架构分析
```
com.nageoffer.ai.ragent
├── admin/        ← 运维仪表盘
├── core/         ← 通用核心组件（分块、解析）
├── ingestion/    ← 文档采集管道
├── knowledge/    ← 知识库管理
├── rag/          ← RAG 智能问答（最核心、最复杂）
└── user/         ← 用户认证
```
