infra-ai模块是项目的 **AI 基础设施层**，负责封装所有与 AI 模型交互的基础能力——Chat、Embedding、Rerank、模型路由、健康检查。它向上层（`bootstrap/rag`）提供统一接口，隐藏不同模型提供商的差异。

### 4. [`model/`](file:///D:/IDEA-java/ragent/infra-ai/src/main/java/com/nageoffer/ai/ragent/infra/model) — 模型路由与健康管理

| [ModelCaller](file:///D:/IDEA-java/ragent/infra-ai/src/main/java/com/nageoffer/ai/ragent/infra/model/ModelCaller.java) | 泛型函数式接口，统一 Chat/Embedding/Rerank 的调用签名 |

**模型路由的完整链路**：
```
selector.selectCandidates(capability)  →  [模型A(优先级1), 模型B(优先级2), 模型C(优先级3)]
                                      ↓
executor.executeWithFallback(candidates, callable)
  → try 模型A → 成功 → 返回
  → 失败（超时/5xx/限流）→ 熔断模型A → try 模型B → 成功 → 返回
  → 失败 → 熔断模型B → try 模型C → ...
  → 全部失败 → 抛异常
```

## 设计模式总结

| 模式 | 应用 |
|---|---|
| **策略模式** | `ChatClient` / `EmbeddingClient` / `RerankClient` 接口 + 多提供商实现 |
| **模板方法** | `AbstractOpenAIStyleChatClient` / `AbstractOpenAIStyleEmbeddingClient` 提供 HTTP 骨架，子类覆写 `provider()` / `maxBatchSize()` 等钩子 |
| **装饰器** | `ForwardingStreamCallback` 拦截流式回调事件 |
| **门面模式** | `LLMService` / `EmbeddingService` / `RerankService` 向上层隐藏路由实现 |
| **熔断器** | `ModelRoutingExecutor` + `ModelHealthStore` 三态熔断 + 自动恢复 |

**一句话总结**：`infra-ai` 是"**AI 模型的统一网关**"——向上层提供 Chat / Embedding / Rerank 三个能力的统一接口，向下屏蔽不同提供商（硅基流动、AIHubMix、Ollama、百炼）的差异，内置模型路由、熔断降级和健康监控。
