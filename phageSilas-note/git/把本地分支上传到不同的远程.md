
你现在在 `GaoSiJun` 分支上，改动还没 commit，想把这批改动推送到远程 `Common` 分支。最简单的方式是**先把改动搬到 Common 分支上再提交**：

## 操作步骤

```bash
# ① 暂存当前所有改动
git stash

# ② 切到 Common 分支
git checkout Common

# ③ 把改动还原到 Common 上
git stash pop

# ④ 暂存并提交
git add .
git commit -m "feat(common): 你的提交说明"

# ⑤ 推送到远程 Common
git push origin Common

# ⑥ 切回 GaoSiJun 继续干活
git checkout GaoSiJun
```


---

## 流程图

```
GaoSiJun:  [未提交的 common 改动]
                ↓ stash
            存起来
                ↓ checkout Common
Common:     [cherry-pick①]--[cherry-pick②]
                ↓ stash pop
            [cherry-pick①]--[cherry-pick②]--[新的 common commit]
                ↓ push
            origin/Common ✅
```


---

> 这样就不需要 cherry-pick 了，改动直接落在 Common 分支上，干净利落。提交说明按 Conventional Commits 格式写就行，比如 `feat(common): 优化xxx方法`。
