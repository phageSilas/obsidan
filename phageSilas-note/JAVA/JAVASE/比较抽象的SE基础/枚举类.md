枚举（`enum`）是 Java 5 引入的一种特殊类，专门用来表示**一组固定的常量集合**，比如星期、性别、订单状态、颜色等。相比直接使用 `int` 或 `String` 常量，枚举提供了**类型安全、可读性强、功能丰富**等诸多优势。

---

## 1. 枚举的基本定义

最简单的枚举只需列出所有常量：

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
```

使用枚举常量时直接用 `枚举名.常量名`：

```java
Day today = Day.MONDAY;
System.out.println(today); // MONDAY
```

---

## 2. 枚举的本质：特殊的类

每个枚举常量实际上都是该枚举类型的**一个 `public static final` 实例**。所有枚举都隐式继承自 `java.lang.Enum`，因此它**不能再继承其他类**，但**可以实现接口**。

编译器会为枚举自动生成以下方法：
- `values()`：返回包含所有枚举常量的数组。
- `valueOf(String name)`：根据字符串名称返回对应的枚举常量（大小写敏感）。
- `name()`：返回枚举常量的名字，与声明时完全一致。
- `ordinal()`：返回枚举常量的声明顺序，从 0 开始。
- `toString()`：默认返回 `name()`，可以重写。

```java
// 遍历所有常量
for (Day d : Day.values()) {
    System.out.println(d.ordinal() + " : " + d.name());
}

Day d = Day.valueOf("MONDAY"); // MONDAY
Day.valueOf("monday");          // ❌ IllegalArgumentException
```

## 3. 在 `switch` 中使用枚举

枚举天生适合配合 `switch` 使用：

```java
switch (today) {
    case MONDAY: System.out.println("周一综合症"); break;
    case FRIDAY: System.out.println("TGIF"); break;
    default: System.out.println("普通工作日");
}
```

从 **Java 14** 开始，你可以使用更灵活的 `switch` 表达式，编译器会检查分支是否覆盖所有枚举常量：

```java
String mood = switch (today) {
    case MONDAY -> "😫";
    case FRIDAY -> "😎";
    case SATURDAY, SUNDAY -> "🎉";
    default -> "😐";  // 如果没有覆盖所有常量，编译器会强制要求 default
};
```

## 4. 为枚举添加字段、构造器和方法

枚举可以有成员变量、构造器（**必须是 `private`，且可以省略 `private` 修饰符**）和自定义方法，这使得每个枚举常量可以携带更多信息。

```java
public enum Planet {
    // 枚举常量，后面括号中的参数会传递给构造器
    MERCURY(3.303e+23, 2.4397e6),
    VENUS  (4.869e+24, 6.0518e6),
    EARTH  (5.976e+24, 6.37814e6),
    MARS   (6.421e+23, 3.3972e6);

    private final double mass;   // 质量（kg）
    private final double radius; // 半径（m）

    // 构造器必须是私有的（不加 private 修饰符也默认为 private）
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    public double getMass() { return mass; }
    public double getRadius() { return radius; }

    // 计算表面重力
    public double surfaceGravity() {
        final double G = 6.67300E-11;
        return G * mass / (radius * radius);
    }
}
```

使用：
```java
System.out.println(Planet.EARTH.surfaceGravity());  // 9.802...
```

## 5. 枚举中的抽象方法与“常量特定类主体”

你可以在枚举内部声明抽象方法，然后让每个常量以**匿名内部类**的形式提供自己的实现。这通常被称为 **“常量特定方法实现”**。

```java
public enum Operation {
    PLUS {
        @Override
        public double apply(double x, double y) { return x + y; }
    },
    MINUS {
        @Override
        public double apply(double x, double y) { return x - y; }
    },
    TIMES {
        @Override
        public double apply(double x, double y) { return x * y; }
    },
    DIVIDE {
        @Override
        public double apply(double x, double y) {
            if (y == 0) throw new ArithmeticException("除零");
            return x / y;
        }
    };

    // 抽象方法，每个常量都必须实现
    public abstract double apply(double x, double y);
}
```

调用：
```java
double result = Operation.PLUS.apply(5, 3); // 8.0
```

## 6. 枚举实现接口

枚举可以实现接口，但无法继承类。这允许将枚举用于多态场景。

```java
interface Greetable {
    String greet();
}

public enum Weekday implements Greetable {
    MONDAY, TUESDAY, WEDNESDAY;

    @Override
    public String greet() {
        return "Hello, today is " + this.name();
    }
}
```

## 7. 枚举的集合：`EnumSet` 和 `EnumMap`

专门为枚举设计的高效集合，内部使用位向量或数组实现，性能极佳。

### `EnumSet`
一个抽象类，只能通过静态工厂方法创建，元素必须是同一枚举类型的常量。内部实现非常紧凑（当枚举常量数 ≤ 64 时，用一个 `long` 的位表示整个集合）。

```java
EnumSet<Day> workDays = EnumSet.range(Day.MONDAY, Day.FRIDAY); // 周一至周五
EnumSet<Day> weekend = EnumSet.of(Day.SATURDAY, Day.SUNDAY);
EnumSet<Day> allDays = EnumSet.allOf(Day.class);
```

### `EnumMap`
Key 必须是枚举类型，内部用数组存储，效率远超普通 `HashMap`。

```java
EnumMap<Day, String> plan = new EnumMap<>(Day.class);
plan.put(Day.MONDAY, "会议");
plan.put(Day.FRIDAY, "团建");
System.out.println(plan.get(Day.MONDAY)); // 会议
```

## 8. 枚举实现单例模式

由于枚举的构造器默认私有，且 JVM 保证每个枚举常量只会被实例化一次，枚举是实现单例的最佳方式，天然线程安全，还能防止反射和序列化破坏。

```java
public enum DatabaseConnection {
    INSTANCE;

    public void connect() {
        System.out.println("连接数据库...");
    }
}

// 使用
DatabaseConnection.INSTANCE.connect();
```

---

## 9. 枚举的序列化

枚举的序列化机制非常特殊：JVM 保证在反序列化时，每个枚举常量是唯一的，不会创建新实例。因此你**无需担心单例被破坏或字段丢失**，枚举常量是天生适合序列化的常量。

> 注意：如果枚举中定义了一些非瞬态的自定义字段（如上面的 `mass`、`radius`），在序列化时也会被保存和恢复，但通常不推荐在可序列化枚举中加入大量可变状态。

## 10. Java 新版本对枚举的增强

- **`switch` 表达式**（Java 14+）：与枚举搭配，编译器能检测分支完整性，避免遗漏。
- **模式匹配**：虽然枚举本身不是 `record`，但结合 `sealed` 接口，枚举常用于受限层次结构中。例如：

```java
sealed interface TrafficLight permits Red, Yellow, Green {}
enum Red implements TrafficLight { INSTANCE; }
enum Yellow implements TrafficLight { INSTANCE; }
enum Green implements TrafficLight { INSTANCE; }
```

## 11. 注意事项与最佳实践

1.  **不要滥用 `ordinal()`**  
    `ordinal()` 会随着常量顺序变化而改变，其值没有语义。如果需要数值编码，**显式定义字段**（如 `int code`）。

    ```java
    public enum Status {
        PENDING(1), PROCESSING(2), COMPLETED(3);
        private final int code;
        Status(int code) { this.code = code; }
        public int getCode() { return code; }
    }
    ```

2.  **`values()` 的陷阱**  
    每次调用 `values()` 都会返回一个新数组，频繁调用会有开销。如果需要多次使用，建议缓存。

3.  **枚举中的抽象方法 vs. `switch`**  
    当每个常量行为不同时，优先使用常量特定方法实现，而不是在外部写一个庞大的 `switch`，这样更符合开闭原则，新增常量时编译器会强制实现抽象方法。

4.  **枚举常量命名**  
    遵循常量命名规范：全部大写，下划线分隔单词（`MAX_SIZE`）。

5.  **不要过度使用枚举**  
    枚举适合固定不变的常量集。如果常量集可能动态变化（例如从数据库加载），则应使用普通类或字符串。

---

## 总结

Java 枚举远不止是一组命名常量，它是一个功能完备的类，支持字段、方法、接口实现和抽象方法，还能利用 `EnumSet`、`EnumMap` 获得高性能集合。正确使用枚举可以让你的代码**类型更安全、意图更清晰、维护更容易**，是现代 Java 编程中不可或缺的一部分。
