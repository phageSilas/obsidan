在 Java 中自定义注解非常简单，核心就是使用 `@interface` 关键字，并结合**元注解**来限定它的作用范围和行为。

### 第一步：定义注解（使用 @interface）

假设我们要定义一个用于**标记接口是否需要记录日志**的注解 `@Loggable`：

```java
import java.lang.annotation.*;

// 1. 元注解：定义作用目标（这里指只能用在类上）
@Target(ElementType.TYPE)
// 2. 元注解：定义生命周期（这里指运行时保留，以便反射读取）
@Retention(RetentionPolicy.RUNTIME)
// 3. 元注解：让该注解包含在 Javadoc 中（可选）
@Documented
public @interface Loggable {
    // 4. 定义属性（注意：这里看起来像方法，实际上是属性）
    String value() default ""; // 默认值为空字符串

    int level() default 1;     // 默认级别为 1
}
```

---

### 第二步：认识关键的元注解（必须掌握）

在定义时，最常用的是以下三个元注解：

-   **`@Target`**：限制注解可以贴在哪里。
    -   `ElementType.TYPE`（类/接口）
    -   `ElementType.METHOD`（方法）
    -   `ElementType.FIELD`（字段）
    -   `ElementType.PARAMETER`（参数）
    -   支持多个：`@Target({ElementType.METHOD, ElementType.TYPE})`
-   **`@Retention`**：限制注解保留到什么时候（**重要**）。
    -   `RetentionPolicy.SOURCE`：仅源码阶段（如 `@Override`），编译后丢失。
    -   `RetentionPolicy.CLASS`：编译时保留，JVM 加载时丢失（默认）。
    -   `RetentionPolicy.RUNTIME`：**运行时保留**，可以通过反射读取（**90% 的自定义注解都用这个**）。
-   **`@Documented`**：生成 API 文档时是否包含该注解。

---

### 第三步：注解属性的数据类型

注解支持的数据类型有限，必须是以下几种：

1.  基本类型（`int`, `double`, `boolean` 等）
2.  `String`
3.  `Class` 类型（如 `Class<?>`）
4.  枚举（`Enum`）
5.  其他注解
6.  以上类型的**数组**（例如 `String[] names()`）

> **注意**：属性可以有默认值（使用 `default` 关键字），也可以没有默认值（使用时必须赋值）。如果属性名为 `value` 且只有一个属性，使用时可以省略 `value=`。

---

### 第四步：使用注解

将注解贴到目标类上：

```java
// 使用了 value 属性，level 采用默认值 1
@Loggable(value = "UserService", level = 2)
public class UserService {
    // 业务逻辑...
}

// 如果只有一个 value 属性，可以简写为 @Loggable("UserService")
```

---

### 第五步：通过反射解析注解（核心逻辑）

如果不写代码去读取，注解本身不会产生任何作用。我们通过 **Java 反射机制** 来获取注解信息并执行逻辑：

```java
import java.lang.reflect.AnnotatedElement;

public class AnnotationProcessor {
    public static void main(String[] args) {
        // 获取 UserService 的 Class 对象
        Class<UserService> clazz = UserService.class;
        
        // 判断该类是否贴了 Loggable 注解
        if (clazz.isAnnotationPresent(Loggable.class)) {
            // 获取注解实例（本质上是 JVM 生成的动态代理对象）
            Loggable loggable = clazz.getAnnotation(Loggable.class);
            
            // 读取属性值并执行逻辑
            String module = loggable.value();
            int level = loggable.level();
            
            System.out.println("正在记录日志: 模块=" + module + ", 级别=" + level);
            // 这里可以真正调用 Log4j 或 SLF4J 打印日志
        }
    }
}
// 输出结果：正在记录日志: 模块=UserService, 级别=2
```

---

### 进阶技巧：自定义注解结合 AOP（Spring 常用）

在 Spring Boot 项目中，你通常不会手动写反射代码，而是结合 **AOP（面向切面编程）** 使用。

1.  **定义注解**（同上）。
2.  **编写切面类**，使用 `@Around` 环绕通知，通过 `joinPoint.getSignature()` 获取方法上的注解，实现无侵入式的权限校验、日志打印或接口限流。

---

### 避坑指南（重点提醒）

1.  **Retention 忘了写**：默认是 `CLASS`，如果你用反射 `getAnnotation` 去拿，拿到的会是 `null`。**一定要检查是否写了 `@Retention(RetentionPolicy.RUNTIME)`**。
2.  **Target 限制不匹配**：如果你把注解定义成只能用在 `METHOD` 上，却贴在了类上，编译时会直接报错。
3.  **注解不能继承**：注解本身不支持 `extends`，但可以利用 `@Inherited` 元注解让子类继承父类的注解（仅限于类上的注解，方法上的不继承）。
