大家好,接下来由我讲解本次前端系分,本次项目是由前端框架是用umi,然后配合react,typescript实现的,ui大部分有ant design提供
项目9个模块的页面实现分别对应pages目录下的几个文件夹,并且像api调用,工具函数之类的服务均有对应的文件夹,

**权限模块**的会根据登录时用户的权限决定他们能看到什么,权限字段是前后端共同约定的,登录后会把后端返回的权限字段放入全局状态,之后的渲染路由都会先判断权限是否符合再执行操作

**组织架构**和**员工档案**和**入转调离**三个模块都是增删改查,根据后端返回的数据渲染对应的界面即可

接着说**考勤管理**模块,这个模块主要的设计就是打卡界面由 React 的 `useState` 和 `useEffect` 定时器实现当前时间的每秒刷新,然后个人打卡信息界面的日历视图有Ant Design的Calendar 日历组件展示,其次考勤统计中的折线图、饼图、柱状图之类的各种图由AntV G2 实现,根据后端返回的数据集合进行渲染,(增长率的数据是根据数据库种的信息进行计算的,使用到的箭头是Ant Design 图标库里的箭头)

然后是**薪资管理**模块,他的设计和考勤管理差不多,统计图由AntV G2Plot或者Ant Design Charts实现,不过其中有一些字段脱敏的机制,例如无薪资明细权限时将实发工资显示为 `****.**`，银行卡号只保留前四后四位,不过脱敏的实现很简单,一般就是直接截取
字符串,然后用星号代替,二次验证后再显示就行(是通过usestate, React 重新渲染页面实现的),然后在这个脱敏机制在登陆界面等各种隐私界面都有使用
